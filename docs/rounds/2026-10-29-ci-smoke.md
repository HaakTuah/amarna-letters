# Side lane: the smoke test in CI (29 October 2026)

PR #199, branch `ci/smoke-on-web`. The Playwright smoke test of the built app (`src/web/smoke.mjs`) ran only by hand,
so the map's overlapping names (item 11f+, #196) went unseen.

## What was built

- `.github/workflows/pages.yml`: the `changes` job gains a `web` output, true when a PR changes `src/web/`,
  `src/engine/`, `src/game/` or `src/llm/` (what the app bundles; the map and its names live in the engine), the root
  `package.json`, `package-lock.json`, `tsconfig.json` or `tsconfig.base.json`; never their `test/` folders or `.md`
  files. A `smoke` job runs on it beside `checks` and the test shards: `npm ci`, Playwright 1.63.0 installed with
  `--no-save` (it is not a project dependency), Chromium cached by version, then the build and the smoke test. Publishing
  `main` also waits on it (success or skipped).
- `scripts/cloud-setup.sh`: Playwright 1.63.0 too, the version cloud sessions have; it said 1.49.1. Each file points to
  the other.

## What it caught

Its first run failed: "babylon over badge of susa", "byblos over traveller k-envoy", the cases #196 fixed. They failed
about one run in two on Playwright 1.49.1's Chromium 131 locally, and on CI's runner with 1.63.0 too ("Hatti's view").
With the map in that state, a synthetic `transitionend` cleared both names at once: the last placement had been measured
mid-motion and the real end event never came. `src/web/src/map/svg-renderer.ts` now also hooks every running transform
transition of the zoom, units and travellers, once each, and places again when it finishes or is cancelled, whatever the
events do. Placement only changes visibility, so it cannot start a motion it would wait on.

## Proof and times

- Skipped where the app is untouched: run 40949702233 (workflow and script only), `smoke` skipped.
- Runs where it is touched: run 40955857200, `smoke` passed in 2 min 44 s, beside a longest test shard of 4 min 54 s,
  so a code PR's checks take no longer. Locally: build and smoke about 2 min 20 s.

## Readings taken

- **The engine counts as able to break the drawing.** The map's data, names and coordinates live in
  `src/engine/src/model/`, and the smoke test plays script kings through the engine. Alternative: `src/web/` only,
  cheaper, but blind to a map-data change. Principle: the guard covers what it guards.
- **The renderer fix rides this PR.** The job cannot merge red, the bug is the app's (players on a busy phone see it),
  and no open PR touches the renderer. Alternative: a lane of its own first.
- **The workflow file is outside the filter,** so this PR could show the skip; a later change to the job shows itself by
  touching a file under `src/web/`.

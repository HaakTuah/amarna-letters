## Readings taken and design questions

1. **No call is strict.** "Strict mode only where a malformed reply would do real harm, never for orders, since every reply
   is validated and falls back to a script anyway": the same reasoning holds for every reply in the game today, so none is
   strict and no grammar is compiled. `CallSpec.strict` remains for a call that would need it.
2. **The schema goes as a tool, not as a response format.** Anthropic's JSON response format always compiles a grammar,
   so the non-strict path is a tool. Forced tool choice is refused by Opus and Sonnet 5.5, so the request asks the model to
   call it (`tool_choice` auto, "Answer by calling the reply tool once, with every field filled in."), and a model that
   writes its JSON as text instead is read too.
3. **The check at setup costs nothing on Anthropic** (a token count with the reply tool), and asks a compatible endpoint's
   model list. A non-strict tool compiles no grammar, so the count proves the provider takes the schema and has the model;
   for a strict call it would not prove the grammar compiles, and the limits test covers that case. Each job is checked
   with its largest schema; every other variant only leaves fields out. The first real call is left to Haakon.
4. **Every field is required in validation too.** A reply that leaves a field out is sent back once with what is missing.
   This also applies to file seats, whose replies used to be allowed to leave fields out.
5. **What counts as a fallback**: a decision a model, file seat or local agent was asked for and a script made instead
   (error, refusal, timeout, or a second unfit reply). The share that pauses a game is of those decisions in one season.
   Script and human decisions are not counted.
6. **The Anthropic SDK replaces `fetch`** (the stack table's "the official TypeScript SDK"), at version 0.133.0 (the
   newest more than two weeks old). The worker bundle grew to about 728 KB (the page's bundle is 777 KB, 254 KB
   compressed).
7. **A continued game with another provider** needs that provider set up again on the start page: the log header keeps
   seat labels, not endpoints.
8. **Prices** of models the game does not know default to nothing (free by the meter), with a notice, rather than to a
   guessed price.

## Review

One reviewer (Opus, high effort) on the diff and the item's text. It ran the tests (1,004 passing), the web build and the
smoke test, and checked the keys' handling: the Anthropic key goes only to Anthropic through the SDK, other providers'
keys stay in memory and go only to their own endpoint, and no key is logged, saved or written into the log or settings.
Its one blocking point was this report and the progress file, written in the item's second commit. Fixed from it:

- A continued game that used another provider could not go on: the log keeps seat labels, not endpoints, so its model
  was routed to Anthropic. Continuing now takes the providers, prices and pause share set on the page, and says which
  provider to set up when one is missing.
- A local provider with no key typed failed to start in the browser; it now gets an empty key.
- A call stopped through the SDK (a new game replacing a running one) was taken for a failure and logged as a fallback;
  the SDK's abort is now an abort.
- File seats wrapped as "File seat (sleeping)" (`--sleeping-scripts`) were labelled as models; they are file seats.

Left as noted, not blocking:

- Fallbacks at setup (personas) and at the end (chronicles) are logged with their author but not counted in a season's
  fallbacks; the pause works in auto-play only, and the batch runner has no pause (it reports fallbacks per seat).
- A letter sent from a court held while a king's orders stood takes the author of that season's orders; if the orders
  fell back and the court reply was the model's own, the letter reads as a fallback.
- Touching a price field stores a price of zero, which hides the "no price set" notice; renaming a provider's id leaves its
  key under the old id.
- `CompatibleProvider` sends `max_completion_tokens`, which some local servers ignore; an endpoint that echoes a dated model
  name records no model, so the provider's own fallback is not detected there.
- The game page rebuilds every trail's authors and every season's counts on each update: fine at today's size.
- Every field is now required, so a file seat or local agent that leaves a field out costs a retry (reading 4).

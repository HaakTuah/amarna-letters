# Split the big files (the workshop lane: "The code files near the split line")

Sonnet built this lane (splits are a routine lane). An outside review found 17 code files past 40 KB, `turn/plans.ts`
within a few hundred bytes of the 50 KB split mark (`scripts/sizes.json`). Each is judged against "Split by meaning"
(`core/modules/how-to-work.md`): does it hold one thing people look up on its own, or two? A split goes in its own PR,
behaviour proven unchanged ("Same seed, same game": `scripts/test.sh`, and `scripts/sim.sh --games 50 --seed 1
--verify-replay` when the engine moved).

Sizes are bytes on `main` at 33fab48 (12 November 2026). The files marked **left** are in a branch an open pull request
changes, so they wait for a later pass.

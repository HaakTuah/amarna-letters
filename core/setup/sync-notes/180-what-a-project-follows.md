- **13 November 2026, what a project follows.** Done when the manifest's slots hold a *follows* row (`main` or `releases`, in backticks) wherever the project wants other than what holds without one. With no row, a project whose *owner's account* is not the account the core is under follows the core's releases (`core/README.md`, "How a project takes the core", point 1): from this sync on its `core/scripts/sync.mjs` and its core-moved check take the core only from a release the core's owner cut, a full SHA aside (a copy older than release-1 takes this sync itself with the release's full SHA, as the top of this file says), and say so where none is cut yet; the projects of the core's own owner follow `main` as before. Where that fits, there is nothing to do.

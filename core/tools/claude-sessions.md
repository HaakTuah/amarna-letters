# Claude's part: a session of its own

Read by whoever starts a session of its own in Claude Code, or asks whether one goes on once the session that started
it is archived: the kind `way` (the rule this line answers: `tasks/tools.md`, #492).

- *Starts a session:* yes. A project's conversation starts each of its threads as a session of its own, with its own
  context, usually in the cloud, which reports back to it when it finishes; and `claude --cloud "<the brief>"`, from a
  terminal, starts a cloud session for the repository, which runs in the cloud apart from the terminal. Archiving a
  project archives its threads and stops any that runs, and deleting it removes them; whether a session goes on once
  only the session that started it is archived or ends is not stated (what follows: `roles/adviser.md`). How a way
  starts one stands on its line *Task:* (`tasks/ways.md`). Its documentation (code.claude.com, the pages "Claude Code on
  the web" and "Projects"), read on 20 November 2026.

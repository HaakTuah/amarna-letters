#1083. **22 November 2026**, #1083, a design set out by the owner's adviser and agreed to by the owner, in a chat
     session. The starter kit and the sync become one process that writes what the core owns, from the kit's
     templates and what the project holds, the same for a new repository and one at any earlier copy, and never writes
     over the project's own rules: it takes the core's marked part of a rule file alone, and leaves any other file it
     would write as a difference. A script run from the core's `main` proves what it wrote, so a sync that carries it
     stays a pure sync, reviewed once in the core's own pull request, and widens floor rule 8's pure sync to it. The
     reason: a release asked 63 things of each project, 19 of them workflow changes each with two security reviews,
     built by hand from the notes, and a project of another owner held 25 differences from what the kit writes for a
     new one. It stands behind "One process takes the core in" in `AGENTS.md` and floor rule 8's pure sync.

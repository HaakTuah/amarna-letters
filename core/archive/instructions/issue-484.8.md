# The reasons behind the core: issue #484.8

The index, and how an item is written: `archive/instructions.md`.

#484.8. **16 November 2026**, #484, points 8 to 10. A game is sorted by what it is made of, taking each kind that is true
     of it, never by a genre; and a rule a game writes for itself that is true of its kind moves to the core once a
     second game needs it, written for the kind, the game pointing to it. Two games each held rules true of their kind,
     which a new game would have had to find again; the owner agreed to these points as they were added to #484. It
     stands behind "A game takes each kind that is true of it" and "A game's copy of a rule of its kind goes at the sync
     that brings it" in `tasks/game-design.md`, and "A rule of a game's kind moves to the core once a second game needs
     it" in the core's `AGENTS.md`.

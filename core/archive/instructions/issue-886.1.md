#886.1. **19 November 2026**, #886, point 1. A change to the floor or the review guidelines whose only change is a path
     that follows a file moved in the same pull request needs no yes from the owner, where `scripts/path-only.mjs`
     proves it, as `main` holds it: the old path stands no more, the new one holds what the old held, and no other word
     changed. It does not mean that a move changes a rule's text, nor that a pull request that moves a file escapes the
     review it would otherwise get. The yes keeps a session from widening its own mandate, and a pointer that only
     follows a moved file cannot widen it; on 19 November 2026 the owner's yes was asked for a one-word pointer that
     followed a moved file, and the work waited on it. The owner agreed to the point as the issue sets it out, wanting a
     yes only for what means something. It stands behind "The owner's yes in the PR", of floor rule 3, in
     `floor/security.md`.

# Helpers: when they pay

Read by a builder before it starts helpers, however started, and by any session before it writes a
brief: the kinds `helper` and `brief`.

A helper pays only for work of one of these shapes:

- **Parallel and independent:** about three parts or more in different files, needing nothing from each other. Writers
  run in parallel only when their briefs fix every choice they share; otherwise one writer does it.
- **Competing approaches:** two to four candidate fixes, each in its own worktree, measured the same way; the best kept.
- **Bulk to brief:** about ten files or more read to answer one narrow question; it returns file:line and a sentence.
- **Fresh eyes:** a review or an escalation step.

How:
- Not for one-pass work, steps that depend on each other, or waiting on a run.
- At most five at a time, each at its tier and effort: `tasks/roles.md`,
  "The rules name tiers, never a model".
- Check every result before using it.

**A brief is written as a rule is** (#282). Whoever hands a session or helper its work writes its
brief: the orchestrator for each builder, a session for each helper or reviewer it starts, and whoever writes a
template of the starter kit for the sessions that read it.
- By default it stands alone and says four things: the role, by what it does ("you built none of this; find what is
  wrong with it"); the task, with the files it may change; what done looks like, which is what it returns, in what form,
  and where it stops; and the reason.
- Where the task is the owner's word, that goes word for word, the four things around it.
- It gives no title ("an expert"), no stakes that are not real, and no number of the state report as a target
  (`tasks/cleaning.md`, "No process number is a builder's goal").
- It does not mean a brief repeats what its reader reads anyway (`AGENTS.md` and what that names), nor that a template
  that hands no work (a manifest, a threat model) takes the four parts.
- Reason: a session's whole view of its task comes from its brief; in tests a title or a stake changed no score, and
  a stake that is not real is untrue.
- Held by the core's phrase list, which reads its starter kit's templates too, and the review guidelines' point on a
  brief a PR writes; a brief written in the moment, by discipline alone.

# Helpers: when they pay

Read by a builder before it starts helpers, however started (core archive 126).

A helper pays only for work of one of these shapes (core archive 25):

- **Parallel and independent:** about three parts or more in different files, needing nothing from each other. Writers
  run in parallel only when their briefs fix every choice they share; otherwise one writer does it (core archive 60).
- **Competing approaches:** two to four candidate fixes, each in its own worktree, measured the same way; the best kept.
- **Bulk to brief:** about ten files or more read to answer one narrow question; it returns file:line and a sentence.
- **Fresh eyes:** a review or an escalation step.

Not for one-pass work, steps that depend on each other, or waiting on a run. At most five at a time (core archive 61),
each on the cheapest model that does its part well, with a brief that stands alone: its goal, what it returns and in
what form, the files it may change, and where it stops. Check every result before using it.
